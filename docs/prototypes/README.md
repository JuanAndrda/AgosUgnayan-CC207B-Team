# Screen sheets

Contact sheets of the built app's screens at phone, tablet and desktop widths (unmodified). Use them for the UI section of the documentation and for the slides.

- `Buyer/` and `Farmer/`: each role's screens
- `Marketplace/` and `Messages/`: those features on phone and wide screens
- `Overview_Responsive_Sheets/`: every screen at mobile and tablet width

There are no separate Admin or Prices images; the Prices screens appear in the Farmer and Overview sheets. The Figma prototype is at https://www.figma.com/design/6iDTiJCeqccRiDczkkpmsF/AgosUgnayan-Prototype.
